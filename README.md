# 🚆 Railway Passenger Analytics Dashboard

## 📌 Project Overview
An interactive Power BI dashboard developed to analyze railway passenger and train data.

## 🎯 Objectives
- Analyze passenger volume
- Understand booking status
- Compare train types and railway zones
- Analyze class and coach-wise passenger distribution
- Identify high-volume states and stations
- Support data-driven railway planning

## 🛠️ Tools & Technologies
- Power BI
- Power Query
- DAX
- Excel
- SQL

## 📊 Key KPIs
- Total Passengers: 50K
- Total Trains: 5.207K
- Average Fare: 1.50K
- Average Age: 42.43

## 📈 Dashboard Analysis
- Passenger by Booking Status
- Passenger by Gender
- Passenger by Train Type
- Passenger by Train Zone
- Passenger by Coach
- Passenger by Class
- Passenger by State
- Passenger by Station

## 🔗 Data Model
Passenger_Data → Train_Info

Relationship:
Many-to-One (*:1)

Common Key:
Train_Number
